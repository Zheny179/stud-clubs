# Журнал интеграции StudClubs

Журнал фиксирует согласование общих артефактов (contract, shared, модель данных), достижение точек интеграции ТИ-1…ТИ-6 и разрешение спорных вопросов при разработке ИС «StudClubs».

Правила ведения:

- Записи вносятся в хронологическом порядке с сквозной нумерацией.
- Существующие записи не редактируются задним числом; для корректировки или отмены решения создаётся новая запись со ссылкой на исправляемую.
- Запись считается действительной только при наличии отметок о подтверждении обоих исполнителей (или при влитии соответствующего PR с одобрением второго участника).
